# Metodología editorial

## Principio fundamental

**Primero el texto; después su contexto; finalmente sus relaciones.**

## Evidencia e interpretación

El proyecto distingue explícitamente entre:

- evidencia observable
- descripción académica
- interpretación
- hipótesis
- tradición religiosa
- afirmación popular no demostrada

No se presenta una hipótesis como hecho.

## Comparación

La semejanza entre dos tradiciones no demuestra por sí misma transmisión.

Antes de hablar de influencia se consideran:

1. cronología
2. proximidad geográfica
3. canales plausibles de contacto
4. evidencia lingüística
5. evidencia textual
6. evidencia histórica
7. posibles alternativas independientes

## Traducción

Cuando sea posible, una obra se estudiará a partir de sus lenguas antiguas y de los testimonios disponibles.

Se distinguirán:

- original o lengua de composición propuesta
- testimonio conservado
- transliteración
- traducción cercana
- traducción legible
- traducciones históricas
- variantes manuscritas
- notas filológicas

Las traducciones modernas con derechos de autor no se incorporarán íntegramente salvo que exista autorización o una base legal aplicable.

## Prehistoria

Para periodos sin escritura se prioriza la evidencia material.

Una pintura, entierro, edificio u objeto puede documentar una práctica o comportamiento sin permitir reconstruir con certeza la creencia que lo motivó.

## Fuentes

Las fuentes se seleccionan por relevancia y calidad académica. Cualquier posible relación comercial o afiliada debe mantenerse separada del criterio académico.

## Transparencia

Cuando la evidencia es insuficiente, el sistema debe decirlo.

Cuando existen posiciones académicas diferentes, se presentan atribuidas y sin convertir la interfaz en un mecanismo para ocultar el desacuerdo.
