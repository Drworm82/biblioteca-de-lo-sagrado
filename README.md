# Biblioteca de lo Sagrado

Biblioteca digital comparada de textos sagrados y religiosos, con contexto histórico, filológico, geográfico y relaciones entre tradiciones.

## Principio editorial

> La biblioteca no establece un canon. Reúne textos.

El proyecto presenta primero la evidencia y después las interpretaciones. Cuando existen variantes manuscritas, traducciones o interpretaciones académicas diferentes, se conservan y se identifican como tales. Cuando una relación entre tradiciones no puede demostrarse, se indica expresamente.

## Arquitectura

El sistema está pensado como una plataforma de datos históricos y textuales, no como una colección de páginas independientes.

- **Biblioteca:** obras, textos, manuscritos y traducciones.
- **Contexto:** historia, filología, arqueología, fuentes y metodología.
- **Atlas:** lugares, regiones, circulación y geografía histórica.
- **Relaciones:** paralelos, contactos, influencias, dependencias, reinterpretaciones y sincretismos.
- **Cronología:** fechas y rangos con incertidumbre explícita.
- **Fuentes:** bibliografía y evidencia trazable.

La biblioteca es la capa principal. Atlas, cronología y relaciones son diferentes formas de explorar los mismos datos.

## Estado

Fase inicial: arquitectura y modelo de datos.

No se ha incorporado todavía un corpus histórico definitivo. Los datos de prueba sirven únicamente para validar el modelo.
